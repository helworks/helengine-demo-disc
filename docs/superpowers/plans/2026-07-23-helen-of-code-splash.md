# Helen of Code Splash Screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an initial-boot splash that loads the standard main menu additively behind a centered, fading Helen of Code logo, then unloads only the splash scene.

**Architecture:** Generate a project-owned `HelenOfCodeSplash` scene containing a post-menu camera, black background sprite, logo sprite, and `HelenOfCodeSplashComponent`. The component requests `DemoDiscMainMenu` additively on its first update, drives the logo and black overlay alpha values through fade-in/hold/fade-out phases, and requests its own scene unload. The build scene configuration makes this scene first for the eight standard non-handheld platforms while DS/3DS remain unchanged.

**Tech Stack:** C# project code modules, generated `.helen` scene assets, `SpriteComponent` alpha tinting, `SceneManager` additive/unload APIs, xUnit source and component tests, editor platform packaging.
