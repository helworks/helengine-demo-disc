# Demo Scene Instruction Overlay Scaling Design

## Goal

Increase the readability of the shared demo-scene instruction overlay across platforms by making the instruction labels and control icons visibly larger and by increasing spacing so the rows do not feel cramped at higher resolutions.

## Scope

This change applies to the shared overlay generator in `assets/codebase/rendering.tools/DemoSceneInstructionOverlayFactory.cs`.

It covers:

- desktop and console instruction rows generated by `CreateDesktopInstructionOverlayRoot`
- Nintendo DS instruction rows generated by `CreateNintendoDsBottomInstructionRoots`
- the `Rotate Camera` row
- the `Toggle Light` row
- the D-pad icon row assets and layout

It does not change:

- unrelated HUD text
- scene-specific handwritten overrides
- generated output files directly

## Approved Behavior

- Increase instruction text scale to approximately `1.6x` the current visual size.
- Increase the D-pad and shoulder-button icon sizes to match the larger presentation.
- Increase row spacing and label/icon offsets so the larger content has more breathing room.
- Keep the change shared across all scenes that consume `DemoSceneInstructionOverlayFactory`.

## Implementation Direction

Update the sizing and layout constants used by:

- `CreateDesktopInstructionOverlayRoot`
- `CreateDesktopInstructionRow`
- `CreateNintendoDsBottomInstructionRoots`
- `CreateNintendoDsInstructionRow`

The implementation should prefer shared constants for overlay row sizing rather than scattering new magic numbers through individual call sites.

## Verification

- Add a source-level test that locks the shared row sizing and spacing behavior in the generator path.
- Run the smallest relevant city-repo verification for that test.
- Rebuild and visually verify in runtime that `Rotate Camera`, `Toggle Light`, and the D-pad prompt are larger and more comfortably spaced.
