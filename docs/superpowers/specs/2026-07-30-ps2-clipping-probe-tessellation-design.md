# PS2 Clipping-Probe Tessellation Design

## Goal

Enable cook-time tessellation on the deterministic 5-by-1-by-5 clipping-probe cube so near-camera rejection can be evaluated with smaller triangles.

## Design

The generated `ClipProbeCube` will opt into the existing constrained-platform component tessellation path. The existing helper will store editor-only per-platform overrides for PS2 and PSP with tessellation enabled and a maximum world-space edge length of 1.0 unit.

The authored cube remains a scaled generated cube. Tessellation occurs only while cooking the PS2 or PSP variant; the source model, material, camera, and runtime clipping implementation remain unchanged.

## Validation

- A focused source contract will require the clipping probe to pass `true` to its existing tessellation-enabled factory argument.
- The render-test scene will be regenerated by the normal build path.
- The PS2 package will be identified as B297, launched through the repository emulator launcher, and checked with HelenUI OCR.
- Visual acceptance requires the tessellated cube to render normally before the camera intersects it; near-camera behavior will then be evaluated separately.
