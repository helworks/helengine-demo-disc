# Main Menu Polish Options

Small, independent improvements for the Demo Disc main menu. Pick one or two at a time so each change can be tested in isolation.

- [ ] Add a very subtle animated grid or scanline background behind the existing purple-black backdrop.
- [ ] Strengthen the title lockup with a small subtitle: `HELENGINE DEMO DISC`.
- [ ] Add a short personal tagline below the title, such as `Built live, one subsystem at a time.`
- [ ] Give each menu item a small category label: `RENDERING`, `PHYSICS`, `TOOLS`, or `GAME`.
- [ ] Add one short, personal description below the selected item.
- [ ] Make the selected item use a brighter purple surface with a thin cyan edge-light.
- [ ] Add a small `>` prompt cursor beside the selected item.
- [ ] Add a restrained blinking status prompt: `READY // ENTER TO LAUNCH`.
- [ ] Add a footer with engine version, current platform, and build date.
- [ ] Add `Made by Helena / Helen of Code` to the footer.
- [ ] Use a limited category accent palette while retaining purple as the dominant menu color.
- [ ] Add a slow parallax background made of faint transform gizmos, node graphs, or wireframe geometry.
- [ ] Add occasional hand-written demo descriptions, for example: `A very unreasonable number of cubes.`

## Recommended order

1. Selected-item cyan edge-light.
2. Category labels.
3. Footer identity line.
4. Title subtitle and personal tagline.
5. Background treatment.

Avoid adding multiple animated or decorative systems until the menu still feels clear and fast to navigate with just the first four changes.
